# Tic-Tac-Toe Game
A fun, dog-themed twist on the classic Tic-Tac-Toe game built with HTML, CSS, and JavaScript. Players take turn placing cute dog-related icons on the board to line up three icons; the mechanism of winning is automatically detects by the combination and draws a line through the winning row, column or diagonal. The winner is celebrate with music.
