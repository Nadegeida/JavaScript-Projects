# Calculator
A basic 4 function. Users can add, subtract, multiply and divide on a sleek web version of a calculator.

# Tic-Tac-Toe Game
A fun, dog-themed twist on the classic Tic-Tac-Toe game built with HTML, CSS, and JavaScript. Players take turn placing cute dog-related icons on the board to line up three icons; the mechanism of winning is automatically detects by the combination and draws a line through the winning row, column or diagonal. The winner is celebrate with music.

# Pizza Menu
This project provides a clean and user-friendly menu interface where customers can customize their pizza step-by-step. It is a dynamic web application built with HTML, CSS and JavaScript that allow users to build a custom pizza order, select toppings, and calculate the total price in real time.
